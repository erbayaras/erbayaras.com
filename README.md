# erbayaras.com — Erbay Aras Photography & Films

Tek sayfalık site: index.html + img klasörü. Tüm fotoğraflar Erbay Aras'a aittir.

## Klasör yapısı
- index.html — sitenin tamamı
- img/dugun, img/belgesel, img/kurumsal — her fotoğrafın iki boyutu var:
  - xxx-k.jpg  → galeride görünen küçük hali (800 px)
  - xxx.jpg    → tıklayınca açılan büyük hali (2000 px)

## Yükleme
- Natro: ZIP içindeki her şeyi public_html klasörüne atın (index.html doğrudan public_html'in içinde olmalı).
- GitHub Pages: index.html ve img klasörünü deponun ana dizinine yükleyin. Tek dosya 25 MB'ı geçmediği için web arayüzünden yüklenebilir.
